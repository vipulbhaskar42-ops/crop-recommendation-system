# AI Crop Recommendation System 🌾

## Project Overview
This project recommends the most suitable crop based on soil nutrients and environmental conditions.

### Input Features
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall

## Machine Learning Models
- Logistic Regression
- Random Forest
- ANN
- Transformer

## Best Model
Random Forest Accuracy: 99.31%

## Technologies Used
- Python
- Scikit-Learn
- Streamlit
- Pandas
- NumPy
- Joblib
